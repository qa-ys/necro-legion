# Некро Легион — прототип

Мобильный некро-сурвайвор: герой-некромант стреляет сам, убитые враги встают скелетами
в его армию, три одинаковых скелета сливаются в более сильного. 20 уровней в шести биомах,
у финала каждого биома свой босс, между забегами — база с алтарём, оружейной, склепом и лавкой.

Играть: https://qa-ys.github.io/necro-legion/

Это WebGL-сборка Unity (портрет, на телефоне на весь экран). Управление — палец по экрану
или WASD. Прогресс хранится в браузере. В паузе есть меню «Читы» для теста.
